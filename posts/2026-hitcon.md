# HITCON 2026 心得

就簡單記錄一下 HITCON 的心得啦。

## 一、去不去的掙扎

我一開始很掙扎要不要去,因為基本上快要開學了,還有一堆事情要做。但是孫燕姿一直叫我去,然後他還說而且是免費的票,還一直慫恿我去。

我原本只要去禮拜五。然後他一直跟我說禮拜六的議程有 Orange 跟 FlyDragon 一定要去,所以呢我又想改成禮拜六,只想禮拜六當天來回。但是呢他又說禮拜五也要去,所以我原本打算禮拜五早上去,然後禮拜六回來。結果到最後呢,他說他要載我去,禮拜四下午載我去,所以我禮拜四下午就出發了。

跟我原本想的完全都不一樣。雖然過程上蠻好玩的,我們在車上聊了很多,而且就是提早去的話還可以早上不用那麼趕。

## 二、第一天

結果隔天早上一大早到場的時候呢,我到的時候他根本還沒起床,所以我也沒有門票,我那天坐了超級久,有夠傷心。

我進去了,就是先拿一袋神奇東西,然後進那個超大的會議室裡面,先聽了開場。開場呢,他們感覺就是有很多活動可以參加 —— 雖然到最後其實真的有去體驗的很少,像工控還有那個焊接我都沒有去,我覺得可能難度太高了吧,I don't know。

### 前三場:體驗都不太好

然後我們就聽了,他開幕結束說我們出去晃一晃,結果呢,我們回來聽這一個超級有名的那個 **Google Project Zero 的 James Forshaw** 講的第一個議程,然後呢,我們回去的時候呢,他就已經沒位置了。我根本沒有想過這種事情,所以我們還只能跑到樓上超遠的地方聽,而且他還是英文的,那個翻譯又跟屎一樣。所以第一場體驗很不好。

那第二場呢,是聽一個日本人講。那個日本人講的時候呢,我是聽翻譯,那個翻譯超奇怪 —— 他先從日文翻成中文,然後他中文再念給直播的人聽,然後直播的人再翻出來翻給英文。所以經過兩層的轉化之後呢,他大概講者講十句,然後我們實際聽到的翻譯就一句,超級傷心。然後到最後,他甚至不翻了,他說什麼服務壞掉之類的,超破。

還有第三個呢,接下來就是什麼 **endpoint audit agent**。這個也是超級硬的啊,因為那個人呢,他根本是在照稿念,他其實沒有表達得很清楚,所以其實這個體驗也沒有很好。我到這時候,有點後悔來了。

### 後面就不一樣了

接下來就不一樣,接下來講者講的很有趣。他有講說他如何追蹤那個犯罪組織,然後就講他如何用 AI 協助這件事情。他講得蠻生動,雖然有部分聽不懂,但是他把它講的很好聽。

然後就還有聽了一些其他的議程。

第一天的感受沒有到很好,因為其實大部分我都聽不太懂。不過還是見到了很多很有名的人,像是 Allen Own（翁浩正）跟一些熟面孔。

## 三、第二天:議程非常精彩

第二天的議程就非常精彩了。有 FlyDragon 的用 QR code 盜走手機啊,還有 Never gave it up harness 之類的,還有最重要的就是 **Orange**。

![curios講的QRcode盜走LINE](posts/2026-hitcon/curios講的QRcode盜走LINE.jpg)
*curios 講的 QRcode 盜走 LINE*

![AI大叔的harness](posts/2026-hitcon/AI大叔的harness.jpg)
*AI 大叔的 harness*

我得到幾個心得。

**第一個就是,大部分有些講者他是用 AI 做簡報,這 AI 做簡報的問題就是裡面的字太多而且字太小。**

像是我覺得最精彩就是 Orange,他講的東西很有深度,但是他也可以讓我這種沒有學到很深的人也聽得懂。而且他的簡報都看起來就是自己做,他的動畫非常多,可以讓你真只聚焦在他重要的地方 —— 他會像是把背景,哎,不是把背景,就是只讓重點的那行字清楚,其他的霧化的那種,就是非常好。而且他這個挖洞做的超級有趣,他講的超級有趣的。**就覺得 Orange 好強。**

哦,然後我忘記去印實體的背具的 NFC 的卡片了,我太晚去了,傷心哭啊。

## 四、總結

反正我覺得 HITCON 就是一個目前對我來說是有點高難度,但是還是可以學到很多。哎,不算學到很多,就是上開開眼界,OK。

學測完就開始卷資安。拜拜。

## 補充:AI 很強,但還是需要人類

補充一下,有一場是在講他研究駭客組織用 AI 攻擊的部分。是很明顯的 **AI 還是會犯錯**,而且那個駭客組織甚至完全沒有看 AI 寫的 code 就直接用了。他把 API key 丟在網路上,他的 API key 還沒有存好,並讓那個講者直接一直用。

所以 AI 很強,但是還是需要人類的。
