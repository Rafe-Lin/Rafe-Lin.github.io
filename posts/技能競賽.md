#### 子題 7
- facl（Filesystem Access Control List，檔案存取控制清單）
- 練習時要先自己建立目標
- 傳統的 chmod 只能針對 擁有者 (Owner)、群組 (Group) 與 其他人 (Others) 做設定，但題目要求「只針對 webadmin 一個人」進行限制，這就是 `facl`
- 要限制 ssh 指令，首先要找到它存在哪裡。`which ssh`，通常會回傳 /usr/bin/ssh。
- `sudo setfacl -m u:webadmin:--- /usr/bin/ssh`
`setfacl`：設定檔案存取控制清單。
`-m`：代表 modify (修改)，用來新增或變更權限。
`u:webadmin:---`：針對 u (user) 使用者 webadmin 給予 --- (無權限)。
- `getfacl /usr/bin/ssh` 確認

#### 子題 8
- 管理誰可以使用 sudo 的核心檔案是 /etc/sudoers。但絕對不要直接用 vi 或 nano 開啟它，因為一旦語法寫錯，整台系統的 sudo 功能可能會掛掉。

1. 使用正確的工具：visudo
邏輯： visudo 會在存檔前自動檢查語法，如果寫錯了它會警告你，這是比賽中避免低級錯誤的保險。

操作： 使用原本具備 sudo 權限的帳號（題目提供的 deff），輸入： sudo visudo

2. 理解語法結構
你需要在檔案末尾新增一行，其邏輯結構如下： 使用者 登入主機=(執行身份) 指令路徑

使用者： webadmin

登入主機： ALL（代表從任何地方登入都適用）。

執行身份： (ALL:ALL)（代表可以模擬任何使用者或群組身份）。

指令路徑： /usr/bin/ssh（務必使用絕對路徑，可先用 which ssh 確認）。

因此，你要加入的那一行是： webadmin ALL=(ALL:ALL) /usr/bin/ssh

- 驗證成功 
你需要展示從一般使用者切換為 webadmin，並成功使用 sudo 的過程。 指令順序如下：

`su - webadmin` (切換使用者) 密:`password`
`sudo ssh localhost` (嘗試以 sudo 執行 ssh)

#### 子題 9
- iptables 是控制進出流量的最基本工具。要禁止 Ping，本質上就是禁止 ICMP 協定的 echo-request 封包。
iptables 就像是主機的門神，規則由上而下執行。我們要針對「進入」這台主機（lyonus）的封包做過濾。
 `sudo iptables -A INPUT -p icmp --icmp-type echo-request -j REJECT`

`-A INPUT`：在 INPUT 鍊（進入主機的流量）中 Append (新增) 一條規則。

`-p icmp`：指定協定為 ICMP。

`--icmp-type echo-request`：精確鎖定 Ping 的「請求」封包。

`-j REJECT`：拒絕。

這題考驗的是 **iptables 的 NAT（網路位址轉譯）** 功能，目的是將 Linux 伺服器變成一個「透明轉發器」

---


### 2. 環境確認 (必要基礎)
根據試題卷資訊，請確認以下 IP 已經設定正確：
* **Harden01-LinuxServer (來源)**：`192.168.13.120` 
* **Harden01-WinSRV2019CHT (目的地)**：`192.168.13.110` 

---

### 3. 詳細操作步驟

請在 **Linux 伺服器** 上執行以下指令：

#### **第一步：啟用核心轉發 (IP Forwarding)**
Linux 預設不會幫忙轉送封包，必須先打開開關：
```bash
sudo sysctl -w net.ipv4.ip_forward=1
```


#### **第二步：設定 PREROUTING (修改目的地)**
當流量「進來之前」，將目的地從 Linux (120) 改成 Windows (110)：
```bash
sudo iptables -t nat -A PREROUTING -p tcp --dport 80 -j DNAT --to-destination 192.168.13.110:80
```

#### **第三步：設定 POSTROUTING (確保回程路徑)**
為了讓 Windows 知道要把回應傳回給 Linux（而不是直接傳給客戶端導致連線失敗），我們需要進行偽裝 (Masquerade)：
```bash
sudo iptables -t nat -A POSTROUTING -j MASQUERADE
```

請使用setfacl指令，限制IT群組不能執行find指令。 (2) 請將指令畫面、設定前的驗證畫面及設定後的驗證畫面，截圖貼至答案卷試題11中，並在畫面中框出關鍵部分，同時附上解題過程簡要說明。




-  環境準備（如果你的環境是空的）

在開始解題前，你的系統必須先有 **IT 群組** 與一個屬於該群組的 **測試帳號**。
1.  **建立 IT 群組**：`sudo groupadd IT`
2.  **建立測試使用者並加入 IT 群組**：`sudo useradd -m -g IT it_member`
3.  **設定密碼**：`sudo passwd it_member` (設定為 `Skills54@`)

---

 3. 詳細解題步驟

 **第一步：確認指令路徑與設定前驗證 (截圖 1)**
1.  **找出 find 的位置**：輸入 `which find`。 (通常是 `/usr/bin/find`)
2.  **以 IT 成員身份測試**：
    * 切換使用者：`su - it_member`
    * 執行指令：`find /tmp`
3.  **預期結果**：應該可以正常執行並列出檔案。
4.  [cite_start]**截圖重點**：截下 `it_member` 成功執行 `find` 的畫面。 [cite: 80]

 **第二步：下達 setfacl 限制指令 (截圖 2)**
1.  切換回管理員：`exit`
2.  **下封鎖指令**：
    ```bash
    sudo setfacl -m g:IT:--- /usr/bin/find
    ```
3.  **參數詳細解釋**：
    * **`setfacl`**：設定檔案存取控制清單。
    * **`-m` (modify)**：修改現有的 ACL 規則。
    * **`g:IT` (group)**：指定對象為 `IT` 群組。
    * **`---`**：將讀、寫、執行權限全部拿掉（權限值為 $0$）。
    * **`/usr/bin/find`**：目標檔案路徑。
4.  **查看設定結果**：輸入 `getfacl /usr/bin/find`。
5.  [cite_start]**截圖重點**：截下輸入指令的畫面，以及 `getfacl` 顯示 `group:IT:---` 的內容。 

 **第三步：設定後驗證 (截圖 3)**
1.  再次切換使用者：`su - it_member`
2.  再次執行指令：`find /tmp`
3.  **預期結果**：系統應顯示 `bash: /usr/bin/find: Permission denied` (拒絕往來)。

#### 試題12 (2分)
(1)
請異動現有設定，將登入系統前的IP地址關閉顯示。

(2) 請將指令畫面、異動前的設定檔畫面、異動後的設定檔畫面、設定前的登入畫面及設定後的登入畫面，截圖貼至答案卷試題12中，並在畫面中框出關鍵部分，同時附上解題過程簡要說明。


#### **📸 截圖 1：設定前的登入畫面**
我們要先證明原本畫面上看得到 IP。
1.  **如何看到登入畫面？** 最快的方法是在你的虛擬機中，按下鍵盤的 **`Ctrl` + `Alt` + `F2`**（這會切換到第二個純文字終端機 `tty2`），畫面會出現 `login:` 提示字元。
2.  **預期結果**：在 `login:` 的上方，你應該會看到類似 `Ubuntu 20.04 LTS` 以及 `IPv4 address for eth0: 192.168.13.120` 或 `\4` 顯示出來的 IP 資訊。
3.  **截圖重點**：將這個畫面截圖，並把顯示 IP 的那一行**框起來**。
4.  **返回原本畫面**：按 **`Ctrl` + `Alt` + `F1`** (或 `F7`，視環境而定) 切換回原本登入的畫面，或是直接在這個 `tty2` 登入也可以。

#### **📸 截圖 2：異動前的設定檔畫面**
1.  在終端機輸入：
    ```bash
    cat /etc/issue
    ```
2.  **預期結果**：你會看到檔案的原始內容，裡面可能包含 `\4`（代表 IPv4 地址）或直接寫著一串 IP。
3.  **截圖重點**：截圖並框出顯示 IP 相關設定的那一行。

#### **📸 截圖 3：指令畫面 (開始修改)**
1.  使用 `nano` 編輯器開啟檔案：
    ```bash
    sudo nano /etc/issue
    ```
2.  **截圖重點**：截下你輸入 `sudo nano /etc/issue` 這行指令的畫面。

#### **📸 截圖 4：異動後的設定檔畫面**
1.  在 `nano` 編輯畫面中，**刪除**顯示 IP 的那行文字（例如包含 `\4` 或實體 IP 的整行刪掉），你可以只留下 `Ubuntu 20.04 LTS \n \l`，或是為了最高安全性，把它**全部清空**只留空行。
2.  存檔離開：按 `Ctrl+O` $\rightarrow$ `Enter` $\rightarrow$ `Ctrl+X`。
3.  再次輸入 `cat /etc/issue` 驗證。
4.  **截圖重點**：截下修改後 `cat /etc/issue` 乾淨的輸出畫面。

#### **📸 截圖 5：設定後的登入畫面 (拿分關鍵)**
1.  再次按下 **`Ctrl` + `Alt` + `F2`** 切換到登入畫面。（如果畫面沒更新，可以按一下 `Enter` 鍵刷新提示字元）。
2.  **預期結果**：原本顯示 IP 的地方已經不見了，只剩下乾淨的 `login:` 提示。
3.  **截圖重點**：截下這個乾淨的登入畫面，證明 IP 已經被成功隱藏。
